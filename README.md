# ProAct Project Page

Standalone academic project page for:

> World-Calibrated Proposal-to-Action Flow for Vision-Language-Action Models

The layout is inspired by the static-resource organization and visual language of
the [UniMPA project page](https://github.com/JiuTian-VL/UniMPA-page).

Open `index.html` directly in a browser, or serve the directory with any static
web server:

```bash
python3 -m http.server 8000
```

The source repository and paper source remain outside this project-page
repository. Media under `static/` is copied from the local ProAct paper
resources for independent deployment.
